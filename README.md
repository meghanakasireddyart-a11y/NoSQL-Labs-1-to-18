## Technology Stack
- **Primary Database**: MongoDB 7.0+ (Standalone, Replica Set, Sharded Cluster)
- **Polyglot Engines**: Apache Cassandra (Columnar), Neo4j (Graph), Redis (In-Memory Key-Value)
- **Orchestration & DevOps**: Docker, Docker Compose, Kubernetes StatefulSets
- **Language & Drivers**: Python 3.10+, PyMongo, Motor
- **Advanced Topics**: Multi-Document ACID Transactions, RBAC, TLS/SSL, WiredTiger Cache Sizing, Vector Search, HNSW vs IVF, RAG Pipeline, Capstone Fraud Benchmark
